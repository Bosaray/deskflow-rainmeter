# 验证记录

日期：2026-10-23。版本：v0.3.0。

## 自动检查

- `npm run check`：`core.js` 与 `app.js` 的 JavaScript 语法检查。
- `npm test`：数据迁移、输入独立性、任务筛选/排序、日期边界、撤销、备份、Unicode 编码、皮肤生成、进度读回及页面事件流程。
- 页面测试通过轻量 DOM/事件适配器执行真实 `app.js` 与 `index.html`；不包含浏览器排版和系统日期选择器的渲染。

## Rainmeter 实际运行

环境：Windows；Rainmeter 4.5.28.3936（64 位）；Node.js v24.21.0。

使用项目临时设置和临时皮肤运行，透明度为零，禁用更新检查。没有载入用户原来的皮肤布局。验证脚本在测试前要求已有 Rainmeter 进程关闭，并只等待或结束它自己创建的进程。

运行了生成皮肤中的实际完成/恢复命令，记录到：

| 阶段 | 第一项标记 | 已完成数量 | 百分比 |
| --- | --- | --- | --- |
| 首次加载 | ○ | 1 / 3 | 33.33333 |
| 执行完成命令 | ✓ | 2 / 3 | 66.66667 |
| 刷新皮肤后 | ✓ | 2 / 3 | 66.66667 |
| 执行恢复命令并再次刷新 | ○ | 1 / 3 | 33.33333 |

本次日志没有 Rainmeter 运行错误。随后读取 Rainmeter 实际写入的 UTF-16 LE 文件，确认中文内容和编码保留，且 Deskflow 能按任务标识读回 `[false, true, false]`。

复现方式（PowerShell 7）：

```powershell
.\scripts\verify-rainmeter.ps1 -RainmeterPath '你的 Rainmeter.exe 完整路径'
```
